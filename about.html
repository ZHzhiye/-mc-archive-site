📖 关于项目

🎯 项目目标

MC档案馆是一个完全免费、自主开发的 Minecraft 存档与 Mod 分享平台。我们的目标是让玩家能够：

  • 轻松上传并分享自己的游戏存档
  • 发现并下载他人分享的精彩内容
  • 在线解析存档数据，无需启动游戏
  • 管理 Mod 元数据，自动识别版本与依赖

🛠️ 技术栈（规划中）

前端：HTML / CSS / JS
后端：Python FastAPI
存档解析：nbtlib
Mod 解析：@xmcl/mods
数据库：PostgreSQL
存储：对象存储服务
