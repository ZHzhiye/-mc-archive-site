# MC Archive - Minecraft 存档与 Mod 分享网站

## 简介
这是一个 Minecraft 存档和 Mod 分享网站的空壳前端，使用纯 HTML + CSS + JavaScript 构建，无需后端即可运行。

## 文件结构
```
mc-archive-site/
├── index.html    # 首页
├── upload.html   # 上传页面
├── browse.html   # 浏览/下载页面
├── style.css     # 样式表
├── script.js     # 交互脚本
└── README.md     # 说明文件
```

## 如何运行
1. 直接用浏览器打开 `index.html` 即可查看
2. 或使用 VS Code 的 Live Server 插件获得更好的开发体验
