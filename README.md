# MC 档案馆

Minecraft 存档与 Mod 分享平台 - 静态空壳版本

## 页面

- `index.html` - 首页（英雄区 + 功能卡片 + 数据统计）
- `upload.html` - 上传页（存档 / Mod 两个选项卡）
- `browse.html` - 浏览页（筛选器 + 空状态）
- `about.html` - 关于页（项目介绍 + 技术栈）

## 风格

Minecraft 像素/方块主题：
- 草方块配色（绿/棕/灰）
- 飘落方块粒子背景
- 3D 旋转草方块吉祥物
- 像素风阴影与边框
- 数字滚动动画
- 可开关背景音乐（默认静音）
